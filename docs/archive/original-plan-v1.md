### এই সিদ্ধান্তগুলো কী বদলে দিল

**স্ক্রিনশট (প্রতি ৫ মিনিট, র‍্যান্ডম):**
এজেন্ট প্রতি ৫ মিনিটের একটা "উইন্ডো" ধরবে, আর সেই উইন্ডোর ভেতরে র‍্যান্ডম একটা সেকেন্ডে ছবি নেবে —
`slot = [10:00–10:05] → shot @ 10:03:47`, `slot = [10:05–10:10] → shot @ 10:06:12`
তাই ছবি নিয়মিত আসবে (ঘণ্টায় ১২টা) কিন্তু **কখন আসবে কেউ আগে থেকে জানবে না**।

> **নিয়ম:** স্টাফ idle থাকলে বা ব্রেকে থাকলে সেই স্লটের স্ক্রিনশট নেওয়া হবে না — এতে স্টোরেজও বাঁচে, অপ্রয়োজনীয় ছবিও জমে না।

**নতুন স্টোরেজ হিসাব:**
১৫ জন × ৮ ঘণ্টা × ১২/ঘণ্টা = **দিনে ~১,৪৪০টা স্ক্রিনশট**
WebP কম্প্রেশনে (~150 KB) → **~২১৫ MB/দিন**, **~৪.৫–৫ GB/মাস**, ৯০ দিন রাখলে **~১৪ GB**
→ **1 TB SSD-তে বছরের পর বছর চলবে**, চিন্তার কিছু নেই।

**টাইম ট্র্যাকিং লজিক (আপনার চাওয়া অনুযায়ী):**
```
প্রতি ১ সেকেন্ডে চেক (Windows GetLastInputInfo API):

  শেষ input < 60 সেকেন্ড আগে  →  ACTIVE   →  টাইমার চলবে ▶
  শেষ input ≥ 60 সেকেন্ড আগে  →  IDLE     →  টাইমার HOLD ⏸
  আবার mouse/keyboard নড়ল    →  ACTIVE   →  টাইমার আবার চলবে ▶
```
- **Worked time** = শুধু active সেকেন্ডগুলোর যোগফল
- Idle-তে যাওয়ার সময় ওই ৬০ সেকেন্ডও **কেটে নেওয়া হবে** (রেট্রো-অ্যাডজাস্ট), যাতে হিসাব সঠিক থাকে
- প্রতিটা idle পিরিয়ড আলাদা করে লগ হবে → রিপোর্টে "আজ ৬ ঘ ৪২ মি active, ১ ঘ ১৮ মি idle" দেখা যাবে

> ⚠️ **একটা বাস্তব সতর্কতা:** ১ মিনিট থ্রেশহোল্ড খুবই কড়া। কেউ ডকুমেন্ট পড়ছে, ফোনে ক্লায়েন্টের সাথে কথা বলছে, ভিডিও দেখছে বা সহকর্মীর সাথে কাজের আলোচনা করছে — সবই "idle" দেখাবে, অথচ কাজই করছে। তাই আমি এটা **কনফিগারেবল** রাখব (ডিফল্ট ১ মিনিট, আপনি চাইলে ড্যাশবোর্ড থেকে ২/৩/৫ মিনিট করতে পারবেন), সাথে থাকবে:
> - **"Meeting / Call" বাটন** — স্টাফ চাপলে ওই সময় idle গণ্য হবে না (আপনি পরে approve/reject করতে পারবেন)
> - ভিডিও প্লেয়ার বা কল অ্যাপ (Zoom/Meet/Teams) fullscreen-এ থাকলে idle গণনা না করার অপশন
>
> এক মাস চালিয়ে ডেটা দেখে আপনি নিজেই ঠিক করতে পারবেন ১ মিনিট রাখবেন না বাড়াবেন।

## ১. প্রথমে সিদ্ধান্ত: Ready-made কিনবেন, না কি নিজেরা বানাবেন?

### অপশন A — Ready-made SaaS (Time Doctor / Hubstaff / ActivTrak / Insightful)
- **সময়:** ১–২ দিনে চালু
- **খরচ:** ~$7–10 / user / month → ১৫ জনে **মাসে ~$105–150 (৳13,000–18,000)**, বছরে ~৳1.5–2 লাখ, প্রতি বছর চলতেই থাকবে
- **সুবিধা:** কোনো ডেভেলপমেন্ট নেই, সাপোর্ট আছে, মোবাইল অ্যাপ আছে
- **অসুবিধা:** ডেটা বিদেশি সার্ভারে, কাস্টমাইজেশন সীমিত, খরচ কখনো শেষ হয় না

### অপশন B — নিজস্ব সিস্টেম (Self-hosted, custom) ✅ **সুপারিশ**
- **সময়:** ৬–৮ সপ্তাহ (MVP ৩–৪ সপ্তাহে)
- **খরচ:** এককালীন ডেভেলপমেন্ট + মাসে সার্ভার ~৳500–2,000 (অফিসের ভেতরের PC-তে রাখলে প্রায় শূন্য)
- **সুবিধা:** ডেটা ১০০% আপনার দখলে, যা খুশি ফিচার যোগ করা যায়, ১৫ জনের বদলে ৫০ জন হলেও লাইসেন্স খরচ বাড়ে না
- **অসুবিধা:** বানাতে সময় লাগে, মেইনটেইন করতে হবে

**সুপারিশ:** নিজস্ব সিস্টেম। ১৫ জনের জন্য SaaS-এর ২ বছরের খরচেই একটা স্থায়ী সিস্টেম দাঁড়িয়ে যায়। চাইলে ২ সপ্তাহের জন্য একটা SaaS-এর ট্রায়াল চালিয়ে দেখে নিতে পারেন কোন ফিচারগুলো আসলে দরকার — তারপর সেই অনুযায়ী নিজেরটা বানানো।

## ২. সিস্টেম আর্কিটেকচার

```
┌──────────────────────────────────────────────────────────┐
│  ১৫টি Windows PC — প্রতিটিতে oXeio Agent (tray app)      │
│   • র‍্যান্ডম স্ক্রিনশট        • Idle/Active detect         │
│   • Login/Logout time         • Active window/app track  │
│   • Offline হলে লোকাল queue-এ জমা রাখে                   │
└───────────────────────┬──────────────────────────────────┘
                        │  HTTPS (TLS) + device token
                        ▼
┌──────────────────────────────────────────────────────────┐
│  oXeio Server  (অফিসের একটা PC অথবা VPS)                 │
│   • REST API (ingest + query)                            │
│   • PostgreSQL — user, session, activity, event          │
│   • File storage — screenshot (WebP, compressed)         │
│   • Scheduler — রিপোর্ট, পুরোনো ডেটা অটো-ডিলিট           │
└───────────────────────┬──────────────────────────────────┘
                        ▼
┌──────────────────────────────────────────────────────────┐
│  Admin Dashboard (Web — শুধু আপনি ও HR)                  │
│   • Live status  • Timeline  • Screenshot gallery        │
│   • Attendance report  • Export (Excel/PDF)              │
└──────────────────────────────────────────────────────────┘
```

### টেক স্ট্যাক (প্রস্তাবিত)

| অংশ | টেকনোলজি | কারণ |
|---|---|---|
| Windows Agent | **C# / .NET 8 (WinForms tray + Windows Service watchdog)** | নেটিভ Windows API, স্ক্রিনশট ও idle detection সহজ, single .exe, MSI ইনস্টলার |
| Backend API | **Node.js + NestJS** (অথবা Python FastAPI) | দ্রুত ডেভেলপমেন্ট, ভালো ecosystem |
| Database | **PostgreSQL** | নির্ভরযোগ্য, রিপোর্টিং কুয়েরিতে শক্তিশালী |
| Screenshot storage | লোকাল disk অথবা **MinIO** (S3-compatible) | সস্তা, স্কেলেবল |
| Dashboard | **React + Tailwind + Recharts** | দ্রুত, সুন্দর চার্ট |
| Deployment | **Docker Compose** একটা মেশিনে | এক কমান্ডে পুরো স্ট্যাক |

> ⚠️ **গুরুত্বপূর্ণ টেকনিক্যাল পয়েন্ট:** Windows Service (Session 0) থেকে ডেস্কটপের স্ক্রিনশট নেওয়া যায় না। তাই এজেন্টটা **ইউজার সেশনে tray app** হিসেবে চলবে (Task Scheduler → "At log on" দিয়ে অটো-স্টার্ট), আর তার পাশে একটা ছোট **watchdog service** থাকবে যেটা tray app বন্ধ হলে আবার চালু করে দেবে।

## ৩. ফিচার লিস্ট

### 🖼️ A. র‍্যান্ডম স্ক্রিনশট ⭐ *(কনফার্মড: প্রতি ৫ মিনিট)*
- **প্রতি ৫ মিনিটের স্লটে ১টা, স্লটের ভেতরে র‍্যান্ডম সেকেন্ডে** → ঘণ্টায় ~১২টা, দিনে ~৯৬টা/জন
- মাল্টি-মনিটর সাপোর্ট (সব স্ক্রিন একসাথে বা আলাদা)
- WebP কম্প্রেশন ~150 KB → **~215 MB/দিন (১৫ জন), ~৪.৫ GB/মাস**
- **Idle বা break-এ থাকলে ওই স্লটের স্ক্রিনশট স্কিপ** — অপ্রয়োজনীয় ছবি জমবে না
- ইন্টারনেট/সার্ভার ডাউন থাকলে লোকালি queue-তে জমা, পরে অটো আপলোড
- ঐচ্ছিক: ব্লার মোড (পরে দরকার হলে চালু করা যাবে)
- স্ক্রিনশট নেওয়ার সময় ছোট নোটিফিকেশন (স্বচ্ছতার জন্য — সুপারিশকৃত)

### ⏱️ B. টাইম ট্র্যাকার / অ্যাটেনডেন্স ⭐ *(কনফার্মড: ১ মিনিট idle → hold)*
- **Auto clock-in/clock-out** — PC লগইন/লগআউট, lock/unlock, shutdown ধরবে
- **Idle detection — ১ মিনিট** (কনফিগারেবল)। কি-বোর্ড/মাউস না নড়লে **টাইমার hold**, নড়লেই আবার **auto resume**
- প্রতি সেকেন্ডে চেক, ওই ৬০ সেকেন্ড retro-adjust করে বাদ যাবে
- **Active time vs Idle time vs Break** আলাদা হিসাব, প্রতিটা idle পিরিয়ডের লগ
- **"Meeting/Call" বাটন** — মিটিং বা ফোনের সময় idle গণ্য হবে না (আপনার approval সাপেক্ষে)
- **Late arrival / Early leave / Overtime** ফ্ল্যাগ
- **Break button** — লাঞ্চ/নামাজের ব্রেক ম্যানুয়ালি দেওয়া যাবে (ব্রেকের সময় স্ক্রিনশট বন্ধ)
- Manual time entry + approval (মিটিং/ফিল্ড ভিজিটের জন্য)
- ছুটি/লিভ ম্যানেজমেন্ট (Phase 3)

### 📊 C. অ্যাক্টিভিটি ট্র্যাকিং
- Active window title + application name (কোন অ্যাপে কত সময়)
- ব্রাউজারে কোন সাইট (ডোমেইন লেভেল)
- **Productivity category** — Productive / Neutral / Unproductive (আপনি নিজে ক্যাটাগরি সেট করবেন)
- Keyboard/mouse **activity level** (কীলগার নয় — শুধু কতটা অ্যাক্টিভ তার শতকরা হার)
- দৈনিক Productivity Score

### 🖥️ D. অ্যাডমিন ড্যাশবোর্ড
- **Live view** — এখন কে অনলাইন, কে idle, কে অফলাইন
- প্রতি স্টাফের **দিনের টাইমলাইন** (কখন কাজ, কখন idle, কোন অ্যাপ)
- **Screenshot gallery** — তারিখ/স্টাফ ফিল্টার, বড় করে দেখা
- **Reports:** দৈনিক/সাপ্তাহিক/মাসিক অ্যাটেনডেন্স, কাজের ঘণ্টা, লেট রিপোর্ট → **Excel/PDF এক্সপোর্ট**
- **Payroll-ready** ঘণ্টার হিসাব
- **Alerts** — কেউ ৩০ মিনিট idle, কেউ আসেনি, এজেন্ট বন্ধ আছে → ইমেইল/টেলিগ্রাম নোটিফিকেশন
- Role-based access: Super Admin (আপনি) / HR / Team Lead (শুধু নিজের টিম)

### 🔒 E. সিকিউরিটি ও নির্ভরযোগ্যতা
- প্রতিটি PC-র জন্য আলাদা device token, সার্ভারে TLS/HTTPS
- স্ক্রিনশট encrypted at rest, ড্যাশবোর্ডে signed URL দিয়ে দেখা
- **Audit log** — কোন অ্যাডমিন কার স্ক্রিনশট কখন দেখল, তারও রেকর্ড
- **Retention policy** — ৩০/৬০/৯০ দিনের পুরোনো স্ক্রিনশট অটো ডিলিট (ডিস্ক ও প্রাইভেসি দুটোরই সমাধান)
- Watchdog — এজেন্ট বন্ধ হলে অটো রিস্টার্ট; বন্ধ থাকলে অ্যাডমিনকে অ্যালার্ট
- অটো-আপডেট (নতুন ভার্সন এলে ১৫টা PC-তে হাতে হাতে যেতে হবে না)
- সার্ভার ডেটাবেসের রাতের ব্যাকআপ

### 👁️ F. স্বচ্ছতা (Transparency) — বাদ দেবেন না
- Tray-তে সবসময় দৃশ্যমান আইকন (গোপন সফটওয়্যার নয়)
- স্টাফ নিজের সেই দিনের ডেটা/স্ক্রিনশট দেখতে পারবে
- অফিস আওয়ারের বাইরে ট্র্যাকিং সম্পূর্ণ বন্ধ

## ৪. আইনি ও এইচআর দিক (বাস্তবায়নের আগেই করণীয়)

মনিটরিং বৈধ ও বিতর্কমুক্ত রাখতে:

1. **লিখিত Monitoring Policy** বানান — কী ট্র্যাক হবে, কী হবে না, কতদিন ডেটা থাকবে, কে দেখতে পারবে
2. প্রত্যেক স্টাফের কাছ থেকে **স্বাক্ষরিত acknowledgment** নিন (নিয়োগপত্র/অ্যাপয়েন্টমেন্ট লেটারেও ক্লজ যোগ করুন)
3. চালুর আগে **সবাইকে জানিয়ে একটা মিটিং** করুন — লুকিয়ে ইনস্টল করলে টিমের বিশ্বাস নষ্ট হয়, আর আইনি ঝুঁকিও তৈরি হয়
4. **শুধু অফিসের PC, শুধু অফিস আওয়ারে** — ব্যক্তিগত ল্যাপটপ বা বাসার সময়ে নয়
5. পাসওয়ার্ড/ব্যাংকিং স্ক্রিনে যাতে ডেটা না ওঠে — ব্লার মোড বা নির্দিষ্ট অ্যাপ ব্ল্যাকলিস্ট রাখুন
6. কীলগিং (প্রতিটি কী রেকর্ড) **করবেন না** — শুধু activity level রাখুন

## ৬. সার্ভার ও রিসোর্স

**✅ অপশন ১ — অফিসের ভেতরে (নির্বাচিত)**
- একটা মোটামুটি PC: i5 / 8–16 GB RAM / **500 GB–1 TB SSD**, Windows বা Ubuntu
- খরচ প্রায় শূন্য, ডেটা অফিসের বাইরে যায় না, LAN-এ আপলোড দ্রুত
- বাইরে থেকে দেখতে চাইলে Tailscale/WireGuard VPN অথবা Cloudflare Tunnel
- অবশ্যই UPS + অটোমেটেড ব্যাকআপ (দ্বিতীয় ড্রাইভ বা Google Drive-এ)

**অপশন ২ — VPS (DigitalOcean/Contabo/Hetzner)**
- 2 vCPU / 4 GB RAM / 200 GB SSD ≈ মাসে $12–20
- যেকোনো জায়গা থেকে অ্যাক্সেস, আপটাইম ভালো

**স্টোরেজ হিসাব (৫ মিনিট রেটে):** ~৪.৫ GB/মাস → ৯০ দিন রাখলে ~১৪ GB, সারা বছর রাখলেও ~৫৫ GB। **1 TB SSD-তে বছরের পর বছর চলবে।**

## ৭. ঝুঁকি ও সমাধান

| ঝুঁকি | সমাধান |

| স্টাফ এজেন্ট বন্ধ করে দিতে পারে | Watchdog service + অ্যাডমিনকে অ্যালার্ট + non-admin ইউজার অ্যাকাউন্ট |

| সার্ভার ডাউন হলে ডেটা হারানো | এজেন্টে লোকাল queue (৭ দিন পর্যন্ত) + রাতের অটো ব্যাকআপ |
| স্পর্শকাতর স্ক্রিন উঠে যাওয়া | ব্লার মোড, ব্রেক মোড, অ্যাপ ব্ল্যাকলিস্ট |
