# Team output popup beside each bar

Web release **512 / `5ac6ad41dcc6aa8d209ad37ced4fa08c3daba49a`**, 8 November 2026, replaces the below-chart designer breakdown with a floating popup beside the selected bar. Hover, focus or tap opens it. The popup shows the date, daily total, ranked staff names, OX codes and counts from the existing trend response. It chooses the right side when space permits, otherwise the left, and clamps its position to the viewport. The list scrolls when necessary. A short close delay allows the pointer to cross from the bar into the popup. Outside click, Escape, page scroll and resize dismiss it; scrolling within the popup keeps it open. The open bar is highlighted.

The popup uses a React portal under the studio shell, retaining theme variables while avoiding the chart card's overflow clipping. It is a labelled non-modal dialog with a close button; it does not take focus on hover. API attribution/count rules are unchanged.
