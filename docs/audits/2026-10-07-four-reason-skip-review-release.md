# Four-reason skip and immediate replacement — 7 October 2026

Live release **459 / `bc392a2adc624e058cf7f1bdd75c2a4e9b8b5122`** changes the designer Skip picker to **Page Not Found, Event, Copyright, Others**. Page Not Found is accepted without manager review. Every other reason immediately marks the original target `skipped` and creates a manager/owner review request. All four reasons create one durable replacement obligation at skip time; the service attempts to issue one random pool design immediately, without waiting for review. The original skipped target never returns to the pool automatically. An approval leaves it skipped; rejection restores the original assignment and retains any replacement already issued. Skip itself issues only the 1:1 replacement; ordinary goal-based top-up runs on its normal schedule.

Release **460 / `e3cb2b244fad0dd4e2f631166fba9e30b666e19b`** makes each skip and its first replacement an atomic 1:1 swap. It works even when an owner-granted one-day workload puts a designer above the ordinary 30-open ceiling, because the skipped original frees exactly one slot in the same transaction. OX-09's 34-open scenario has a specific regression test. The 60-issued-per-Dhaka-day limit and pool availability still govern immediate delivery; otherwise the obligation remains owed. Later owed sweeps respect the ordinary 30-open ceiling. No permanent cap or daily target changed.
