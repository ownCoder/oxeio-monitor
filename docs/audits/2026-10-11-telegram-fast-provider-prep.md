# Telegram AI fast-provider rollout — 11 October 2026

Owner requested instant useful replies and authorized sending relevant office report facts to an external free AI service. The current local Qwen 1.7B model on three VPS CPUs takes roughly 10–16 seconds on open-ended questions; common direct answers are faster. Groq's documented free tier currently lists `qwen/qwen3.8-27b` at 30 requests/minute and 1,000 requests/day, and the model supports non-thinking mode for quick dialogue. See [rate limits](https://console.groq.com/docs/rate-limits), [model](https://console.groq.com/docs/model/qwen/qwen3.8-27b), and [data controls](https://console.groq.com/docs/your-data). Those limits are external and can change.

Release 490 (`ff084b0ab434e59010c6c1bdf17c3af1ebf40a36`) adds an optional Groq chat-completions path with a 10-second request cap, brief response budget, existing role-based compact facts, and no salary/screenshots/secrets. Tests cover the cloud request and data minimization: 10/10 focused tests, API typecheck and lint passed. VPS API is healthy at public build 490; PostgreSQL container is unchanged. The provider is still `local`; no Groq key exists in the API container and no office data has been sent to Groq.
