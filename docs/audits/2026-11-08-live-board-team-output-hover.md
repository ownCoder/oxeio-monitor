# Live Board Team output designer breakdown — 8 November 2026

Release **509 / `8361cc4a477809d74e7c14f8a43ed8e0edb4b318`** adds a per-person breakdown to the seven daily completed-design bars on Live Board. Hover, keyboard focus, or tap a bar to show each assigned staff member's name, OX code, and completed count. The list is sorted by count. A completed target without an assignee appears as **Unassigned** so the listed counts still add up to the existing daily total. Zero days show “No designs completed”; untracked days remain marked untracked.

The `GET /api/v1/live/trend` response includes `days[].designers`. It groups the same completed target rows already used for `days[].designsFinished`, using the same Dhaka day boundary. Attribution is by `assigned_to_id`, matching the existing live staff cards and daily completion limit. It does not claim the assigned person clicked Complete. The endpoint remains owner/manager only.
