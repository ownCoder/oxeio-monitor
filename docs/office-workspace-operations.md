# Office workspace — ব্যবহারবিধি

Sidebar → **Office**। প্রতিটি section-এ title search, Refresh ও paged records আছে। Owner/manager **Archived** চালু করে record খুলে Restore করতে পারেন। একই record অন্য কেউ edit করলে পুরোনো version save হয় না; reload করে আবার edit করুন।

## Design briefs

Manager আগে Brief templates-এ niche, audience, style, required text, reference note ও expected output লিখবেন। Design briefs → New record-এ design number/ASIN দিয়ে target খুঁজে template apply করে প্রয়োজনমতো বদলে save করবেন। Employee assignment ঐচ্ছিক; designer-এর brief visibility বর্তমান target assignment অনুসরণ করে। Designer নিজে brief edit করতে পারে না।

## Help requests

Designer My Data-তে design-এর **Details & help** দিয়ে বা Office → Help requests থেকে request দিতে পারে। নিজের design, problem type ও সমস্যার বিবরণ দিতে হবে। Manager response/next action লিখে resolved করেন। Request-এ design assigned থাকে; Skip, Complete, hours বা payroll বদলায় না। পুরোনো request-এর সঙ্গে আরেক staff-এর target মেলানো যায় না।

## Submission checks

Manager Checklist templates-এ items, required format ও dimensions নির্ধারণ করবেন। Designer নিজের target ও current checklist বেছে items tick করবেন। **Read file details** PNG/JPEG file name ও dimensions PC-তেই পড়ে; file upload হয় না। AI/PSD/SVG dimensions নিজে দিতে হয়। Format, dimensions, number prefix ও অসম্পূর্ণ checklist-এর warning server-এ তৈরি হয়।

এটি technical advisory check; Complete বা visual-quality approval নয়। Originality/copyright প্রমাণ করে না। Checklist version বদলালে পুরোনো version দিয়ে নতুন check save হবে না। Saved check-এ তখনকার items ও warnings থাকে।

## SOP & examples

Manager বাংলা/ইংরেজি instructions ও accepted/rejected example-এর ব্যাখ্যা লিখবেন। Title বা body text দিয়ে search করা যায়; body search case-sensitive। Staff **I have read this version** চাপলে ওই version-এর acknowledgement থাকে। পরিবর্তিত SOP আবার পড়তে হবে। এটি পড়ার record; quiz বা skill certification নয়। প্রথম version-এ example/reference text রাখা যায়; আলাদা file library নেই।

## Equipment

Company asset tag unique। Manager employee assignment, serial, optional existing agent PC link, warranty, equipment state ও repair/handover notes রাখেন। Employee বদলে save করলে history থাকে। Staff নিজের assigned assets পড়তে পারে। এই register PC control/revoke করে না; linked device metadata থাকলেই hardware ownership নিশ্চিত নয়।

## Joining / leaving

Reusable template থেকে employee case তৈরি করুন। Task, responsible person, due date ও done state রাখুন। Template-এর completed marks নতুন template/case-এর নীতি নয়; templates unchecked থাকে। Checklist শেষ করা account deactivate বা device revoke করে না—existing Staff controls দিয়ে সেটা করতে হবে।

## Skills & coaching

Manager skill name, 1–5 assessment, examples/notes, training goal ও follow-up date রাখেন। Staff নিজের record পড়তে পারে। এটি manager-entered development record; activity percentage দিয়ে automatic rating, salary change বা disciplinary action নেই।

## Today ও Production

Today নিজের assigned designs/management workload, scoped open-help count এবং recent follow-up দেখায়। Production-এর আলাদা workspace-এ পূর্বে তৈরি queue/aging, versioned design previews/pinned comments, planning, quality/flow এবং owner-only product results রয়েছে। Digest/monitor-এর external delivery configuration না থাকলে তা enabled হয়েছে বলে ধরে নেবেন না। Existing salary/deposit access rules বহাল।

## প্রথম ব্যবহার

অফিসের সত্যিকারের output requirements অনুযায়ী একটি brief template ও checklist তৈরি করুন, এবং একটি SOP লিখুন। ছোট দলের ব্যবহার দেখে wording/requirements ঠিক করুন। Preview screenshots-এর synthetic examples production-এ seed করা হয়নি; নতুন guessed policy বা staff assessment বসানো হয়নি। Deployment status ও verification [current-state](current-state.md)-এ।
